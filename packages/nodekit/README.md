# @nynxz/zenkit-nodekit

Everything a ComfyUI custom-node pack needs from ZenKit: the Vite build, the ambient `@comfy/*`
types, the machinery to put a Vue component inside a node body, and (via `zenkit-nodekit sync`)
the Python half that has to agree with it.

A pack built on nodekit works on a plain ComfyUI. Panels, the shared viewer and slot links light
up when the ZenKit runtime is installed and degrade when it isn't. The ZenKit code nodekit uses is
`@nynxz/zenkit-client`'s, bundled into nodekit, so a pack doesn't depend on the client.

Full guide: [Nodekit pack pattern](https://github.com/Nynxz/ZenKit/wiki/Nodekit-Pack-Pattern) ·
[Media](https://github.com/Nynxz/ZenKit/wiki/Nodekit-Media) ·
[Panels and canvas](https://github.com/Nynxz/ZenKit/wiki/Nodekit-Panels-and-Canvas).

## Install

```sh
pnpm add -D @nynxz/zenkit-nodekit
pnpm add @nynxz/zenkit-ui       # optional: the themed component set
```

## Layout

```
pack.json              identity: { "namespace": "nynxz", "displayName": "…", "category": "…" }
vite.config.mts        zenPluginConfig(...)
tsconfig.json          your own config + nodekit's comfy.d.ts in `files`
frontend/framework.ts  createNodekit(manifest); everything else imports from here
frontend/main.ts       glob the widgets, registerNodes
frontend/widgets/*.vue one file = one widget io type
frontend/nodes/*.ts    optional: explicit defineNode() modules
nodes/__init__.py      from ._zenkit import comfy_entrypoint
nodes/_zenkit/         generated by `zenkit-nodekit sync`; committed, never edited
web/                   build output; WEB_DIRECTORY = "./web" in __init__.py
```

`pack.json` is read by both halves: `createNodekit(manifest)` at build time, and
`zenkit-nodekit sync`, which writes it into the vendored Python package.

**`vite.config.mts`**

```ts
import { zenPluginConfig } from '@nynxz/zenkit-nodekit/vite'

export default zenPluginConfig({
  name: 'comfyui-yourpack',
  configUrl: import.meta.url,
  srcDir: './frontend', // default './src'
  outDir: 'web', // default 'js'; must match WEB_DIRECTORY
})
```

**`tsconfig.json`**: list `comfy.d.ts` in `files`. An `include` entry is filtered by `exclude`, so
it would be dropped along with `node_modules`.

```jsonc
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "ESNext",
    "moduleResolution": "bundler",
    "strict": true,
    "resolveJsonModule": true,
    "skipLibCheck": true,
    "noEmit": true,
    "paths": { "@/*": ["./frontend/*"] },
  },
  "files": ["./node_modules/@nynxz/zenkit-nodekit/comfy.d.ts"],
  "include": ["frontend/**/*.ts", "frontend/**/*.vue"],
  "exclude": ["node_modules", "web"],
}
```

**`frontend/framework.ts`**

```ts
import { createNodekit, defineNode, openZenPanel, readMediaDrop } from '@nynxz/zenkit-nodekit'
import manifest from '../pack.json'

export const {
  nodeId,
  typeId,
  route,
  settingId,
  registerNodes,
  discoverWidgets,
  discoverNodes,
  widgetTypes,
  mountWidget,
  addNodeHeaderButton,
  mediaLibrary,
  thumbUrl,
  uploadOrReuse,
  mediaInfo,
} = createNodekit(manifest)
export { defineNode, openZenPanel, readMediaDrop }
```

**`frontend/main.ts`**

```ts
import '@nynxz/zenkit-ui/style.css'
import '@nynxz/zenkit-ui/comfy-bridge.css'
import { discoverNodes, discoverWidgets, registerNodes } from '@/framework'

const widgets = import.meta.glob('./widgets/*.vue', { eager: true })
const nodes = import.meta.glob('./nodes/*.ts', { eager: true })
registerNodes([...discoverWidgets(widgets), ...discoverNodes(nodes)])
```

## Python: `zenkit-nodekit sync`

```sh
zenkit-nodekit sync            # write nodes/_zenkit/ from pack.json (idempotent)
zenkit-nodekit sync --check    # CI: exit 1 when it is stale or missing
zenkit-nodekit check-widgets   # CI: every widget_type() has its widgets/*.vue, and back
```

The vendored package gives the pack `NAMESPACE`, `CATEGORY`, `node_id()`, `route()`; `widget_type()`
and friends; node autodiscovery; the media routes below; `Job` progress events; and a
`comfy_entrypoint` that wires them up. Your own route modules are listed in pack.json
(`"python": { "routes": ["server.api"] }`) and registered by the same setup; routes that change
state start with `server.request_allowed(request)` (Host, Origin and JSON checks). Details:
[Nodekit pack pattern](https://github.com/Nynxz/ZenKit/wiki/Nodekit-Pack-Pattern#python-helpers-zenkit-nodekit-sync).

## Adding a widget is adding a file

`frontend/widgets/LoraStack.vue` registers the io type `NYNXZ_LORA_STACK`: the namespace
uppercased, plus the file name in SCREAMING_SNAKE. Your Python declares an input of that type
(`widget_type("LoraStack", list)` from `_zenkit.io_types`). A rename on one side only shows up as
"Required input is missing"; `zenkit-nodekit check-widgets` catches it.

`widget.value` is what serializes into the prompt, and it is not reactive: hold state in a
`ref` / `reactive`, write it back, and call `widget.callback?.(value)`.

Export `widgetOptions` (widget-level: `name`, `minHeight`, `fill`, `serialize`, `default`) or
`nodeDef` (node-level: `is`, `minSize`, `output`, `slotLinks`, `settings`) from a plain
`<script lang="ts">` block in the same file. A second node that reuses a widget type goes in
`frontend/nodes/*.ts` as `export default defineNode({ … })`.

## Media

Widgets store media as refs (`input/sub/name.png`, `output/…`, `temp/…`), the same refs as
ZenKit's `zen.media`.

| Export            | Does                                                                                      |
| ----------------- | ----------------------------------------------------------------------------------------- |
| `readMediaDrop`   | The refs a drop carries; desktop files are uploaded (`upload` hook to reuse server files) |
| `hasMediaDrop`    | For `dragover`                                                                            |
| `uploadMediaFile` | Upload into `input/<subfolder>` via ComfyUI's `/upload/image`                             |
| `mediaRefUrl`     | A `/view` URL for a ref (never a URL ref itself); `viewUrl` does the same for a record    |
| `mediaKind`       | `'image' \| 'video' \| 'audio'` by extension (GIF is an image)                            |
| `mediaLibrary`    | Browses ComfyUI's folders for `ZenMediaPicker` (from `createNodekit`)                     |
| `thumbUrl`        | A cached JPEG poster for a ref, from the pack's route (from `createNodekit`)              |
| `uploadOrReuse`   | `readMediaDrop`'s `upload` hook: reuse a file whose bytes are already in `input/`         |
| `mediaInfo`       | Kind, duration, size, fps and sound of a ref's file, read by the server                   |

The last four need the pack's media routes, which the synced Python serves under `route('media')`:

```
GET /<ns>/media?type=input|output|temp    {"items": [{name, filename, subfolder, type, kind, size, mtime}]}
GET /<ns>/media/thumb?type=&name=&size=   a JPEG poster (images, first frame of videos)
GET /<ns>/media/info?ref=input/a.mp4      {kind, duration, width, height, fps, has_audio}
GET /<ns>/media/find?size=&sha256=        {"ref": "input/sub/name.png" | null}
```

## Also exported

|                                 |                                                                                     |
| ------------------------------- | ----------------------------------------------------------------------------------- |
| `mountWidget`                   | mount a Vue app in a node body; pointer, sizing and value traps handled             |
| `useDragSurface`                | drags inside a node body without the canvas stealing the gesture                    |
| `addNodeHeaderButton`           | a control in the node's title bar                                                   |
| `openZenPanel` / `hasZenPanels` | pop a component into a dockable panel when ZenKit is installed (`null` otherwise)   |
| `openViewer`                    | the shared media viewer; a new tab without ZenKit                                   |
| `registerSlotLink`              | middle-click a slot to spawn and wire a node (`slotLinks` in a `nodeDef` does this) |
